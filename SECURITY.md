# Security and safety issues

If you find a way this app could write the wrong data to a pedal, skip a safety check, or download something other than M-VAVE's official firmware, please report it privately through [GitHub's private vulnerability reporting](../../security/advisories/new) instead of a public issue.

If your pedal stopped working after an update, open a normal [bug report](../../issues/new?template=bug_report.yml) with the app's log: others may hit the same problem.
